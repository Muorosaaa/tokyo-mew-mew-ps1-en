# Decisions

- **Names and honorifics:** keep the original Japanese names (Ichigo, Mint, Lettuce, Pudding, Zakuro, Ringo, Ryou Shirogane, Keiichiro Akasaka, Mashio Akai, Kisshu, Gateau du Roi) and honorifics (-san, -kun, onee-chan, onee-sama). Pudding keeps "na no da", Ichigo keeps "nya". (User, at project start.)
- **Terms:** パラパラ = "Parapara", コンゲン = "Source", キメラアニマ = "Chimera Anima", レッド・データ・アニマルズ = "Red Data Animals", リボーン… = "Ribbon …" attacks.
- **Place names:** Cottage Woods, Strolling Woods, Forest of Truth, Tranquil Woods, Singing Wind Plains, Mystic Spring, Lovely Flower Field, Healing Grove, Ranger Forest, Ranger Cottage, Mountain Path, Iceberg Hideout, Secret Cave, Mystery Cave. Narrow menu boxes use short forms (Cottage Wds, Stroll Woods).
- **Battle HUD tags:** first names only (Mew prefix unreadable at that size); enemy tags "Chimera", "Parasite".
- **Sound effects:** translated to English comic onomatopoeia in the original colours; tile-based ones split across the same tiles, "!" tiles kept.
- **Graphics text is in scope**, including sound effects.
- **Testing:** the user tests each build in their emulator and sends screenshots; with this repo, boot builds with emu.py first.
- **Delivery to the user:** built files + `patch/patch.bat`, which injects into their own Track 1 .bin and keeps a `.original` backup.
- **Staff credits stay Japanese** (D_EFFECT 602, 129 one-line strips; user, 2026-11-09). The strips are legible, but most staff names are kanji with several possible readings and no public English credit to check, so a wrong romanization was judged worse than leaving them. Lines 122-126 are already English. Contact sheets: work/credits/credits_0.png, credits_1.png.
- **Memory-card save titles stay Japanese** (EXE 0x2a60 "東京ミュウミュウ　　　データ００", 0x2a84 "東京ミュウミュウ　システムデータ"; user, 2026-11-09). Only the PS1 BIOS / emulator memory-card manager shows them, never the game.
- **Mint's voice** (user, 2026-11-09): she keeps a prim, superior ojou-sama register in English (わたくし/ですわ): "I suppose", "Whatever do you mean？", "dear", "Naturally." ~170 of her 279 unique lines were reworded; the rest already had it. Pudding's "na no da" and dropped honorifics were deliberately NOT restored (user call).
- **Akasaka's laugh (ふふふ):** "Ha ha" when he is genuinely amused, no laugh at all when it is just a polite smile (the wording carries the warmth). Never "Hehe". Zakuro's quiet laugh is "Heh…". (User, 2026-11-12.)
- **Naturalness pass (2026-11-12):** proposals go to the user as a comparison sheet (work/script/natural_*.py, trial-built with work/script/trial.py) and are applied with work/script/apply.py only after the user picks. Lines from translation memory are overridden in tr/natural.py, keyed by Japanese.
- **Pudding's "na no da" (user, 2026-11-12, replaces the 2026-11-09 call in the Mint entry):** it may be added back where the English dropped it and it reads naturally, at most once per box; boxes that had it two or three times get it once.
- **Fable 5.2 second-opinion pass (user, 2026-11-25):** a read-only Fable review of all 12 chapters (docs/fable-reviewer-brief.md), every proposal picked by the user in chat; Fable only for the review, Opus 5.5 for everything after. Shared Japanese lines: a pick changes every copy said by the same speaker, except rows where the reviewer said the shared English misfits only that scene (replies like うん！, うん、そうだね, どうしたの？ after "congrats"), which change in that scene only. Per-scene English lives in tr/scene_fix.py. A tr/eNNN.py line is edited in place only when every copy of its Japanese gets the same text, because those lines also feed translation memory for copies elsewhere (row 103 once leaked "Me too！" into script 22 that way).
- **Ellipsis on the baseline (user, 2026-11-25):** the full-width … glyph (0xB2) drew its three 2x2 dots at mid-height, Japanese style; tools/build.py english_ellipsis() moves them to rows 14-15, where the English full stop sits, so every … (1,556 in the script, plus menus) reads as three full stops. No text bytes change. Seen in-game: work/qa/warp/ellipsis/boxes_00.png.
- **Title logo in English (user, 2026-11-15, replaces the 2026-11-08 'stays Japanese' ruling):** the user's own English redraw (data/logo/logo_en_source.png) goes into D_SYSTEM 001 via tools/g_logo_en.py: scaled to the original logo's width (247x135, bottom at y 160), hard edges, 32 colours with no dithering so the entry fits its 13,300-byte slot (255 colours overflowed it). The intro animation's logo (Japanese, no ribbon) is a separate asset and is unchanged.
- **Script-wide consistency (user, 2026-11-25):** "RDA" everywhere (no "R.D.A."; row 27 introduces it as "Red Data Animals（RDA）"); the field mouse's ちゅ is always "Squeak" (rows 3097/3105 without the curly quotes: their boxes have no spare bytes); Kisshu's and Gateau's ふふ-laughs follow the Japanese length: ふふ "Heh", ふふふ "Heh heh", ふふふふ or longer "Heh heh heh" (Gateau's scoffing ふっ stays "Heh"; Mashio keeps "Heh"); Mint's ふふ is "Hm hm", never "Hehe". Applied by work/script/consist.py as per-scene overrides at the end of tr/scene_fix.py (53 lines). Already consistent, no change: "big bro", "Yuki-chan", よろしい "Very well".
